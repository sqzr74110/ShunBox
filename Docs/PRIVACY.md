# GitHub 版本隐私说明

- 不要求应用账户，没有广告 SDK、跟踪 SDK 或分析 SDK；GitHub 侧载构建不加载 StoreKit 商品。
- 图片、音频、PDF 和二维码处理在本机完成。导入文件通过用户主动选择的系统文件/照片选择器读取。
- 保存到照片时才申请相册添加权限；麦克风仅在用户启动录音测试时申请，测试录音在本机回放，不识别声纹身份。
- 处理结果保存在应用本机媒体库，直到用户删除或卸载。导入副本和中间文件是缓存，可由应用清理。系统设备备份行为由用户的系统设置管理。
- 选择 iCloud Drive 等文件提供商的文件夹后，应用只在用户选择保存或打开自动保存时写入。云端传输由相应文件提供商管理；这不是作品默认上传到开发者服务器。
- 分享、保存到其他应用或打开 GitHub / Apple 外部链接后，由目标应用或网站按其政策处理数据。外链访问会发生正常的网站网络请求。
- 输出图片重新编码并移除来源元数据，但照片可见内容以及主动写入水印的相机型号/日期不会被自动删除。
- 公开反馈请不要提交敏感原始文件。此声明针对本仓库官方 SIDELOAD 构建，不能代表第三方修改版。
